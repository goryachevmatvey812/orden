# Орден: как установить приложение и подключить уведомления

## 1. Что загрузить на GitHub (замена файлов)
Откройте репозиторий → Add file → Upload files → выберите и загрузите с заменой:
- `index.html`
- `sw.js`
- `manifest.json`
- (иконки `icon-192.png` и `icon-512.png` не менялись)

Правила базы: Firebase → Firestore → Rules → вставить `firestore.rules` → Publish.
Подождите 1-2 минуты и обновите сайт.

## 2. Установка приложения (бесплатно, без магазина)
На сайте есть кнопка «📲» в шапке и страница «📲 Приложение» (вкладка «Энциклопедия»).

**Android (лучше всего Chrome)**
1. Откройте сайт в Chrome.
2. Нажмите «📲» в шапке или «Установить» во всплывающей подсказке.
   Если подсказки нет: меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
3. Подтвердите. Значок «Орден» появится среди приложений. Запускается как обычное приложение.

**iPhone / iPad (Safari)**
1. Откройте сайт в Safari.
2. Кнопка «Поделиться» → «На экран “Домой”» → «Добавить».

**Компьютер (Chrome или Edge)**
Значок установки справа в адресной строке → «Установить».

Яндекс Браузер и некоторые другие браузеры лишь создают ярлык. Для полноценного приложения откройте сайт в Chrome.

## 3. Настоящий APK-файл (по желанию)
1. Откройте pwabuilder.com, вставьте адрес вашего сайта, нажмите Start.
2. Выберите Package for stores → Android → Generate (подпись можно создать автоматически).
3. Скачайте архив, внутри будет файл `.apk` (для установки напрямую) и `.aab` (для Google Play).
4. Загрузите `.apk` в GitHub: ваш репозиторий → Releases → Create a new release → прикрепите файл → Publish.
5. Скопируйте ссылку на файл и вставьте в `index.html` строкой `const APK_URL='...'` (рядом со строкой VAPID). После замены файла на странице «📲 Приложение» появится кнопка «⬇ Скачать APK».
6. Чтобы установить APK: скачайте файл на телефон → откройте → разрешите установку из этого источника.

## 4. Push-уведомления при закрытом сайте (по желанию, нужен тариф Blaze)
Без этого шага уведомления приходят, пока сайт или приложение открыты в фоне.

1. Firebase → ⚙ → Project settings → Cloud Messaging → Web Push certificates → Generate key pair. Скопируйте ключ.
2. Вставьте его в `index.html`: `const VAPID='ВАШ_КЛЮЧ';` и замените файл на GitHub.
3. Firebase → Upgrade → перейдите на тариф Blaze (нужна банковская карта; небольшой объём бесплатный, можно поставить бюджет-лимит).
4. Загрузите в корень репозитория: папку `functions` (файлы `index.js` и `package.json`), `firebase.json`, `.firebaserc`.
5. Откройте shell.cloud.google.com (вход той же почтой, выберите проект orden-carstvie) и выполните по очереди:
   - `git clone https://github.com/ВАШ_НИК/НАЗВАНИЕ_РЕПОЗИТОРИЯ` и `cd НАЗВАНИЕ_РЕПОЗИТОРИЯ`
   - `cd functions && npm install && cd ..`
   - `firebase login --no-localhost` (откройте ссылку, вставьте код)
   - `firebase deploy --only functions`
6. На сайте: ⚙ → «Push-уведомления при закрытом сайте» → включить → разрешить уведомления.

Push приходят на: личные сообщения, упоминания (@имя, @роль, @все), входящие звонки, новые жалобы (владельцу и ролям с правом «Читать жалобы»).

## 5. Проверка
- В шапке «● онлайн».
- «📲 Приложение»: кнопка установки работает, статус push «включены».
- Закройте приложение полностью, напишите себе с другого аккаунта: должно прийти уведомление.

## Что важно знать
- Звонки работают через интернет напрямую между телефонами. В мобильных сетях иногда нужен TURN-сервер: если звонок не соединяется, в файле `index.html` найдите `const TURN={url:'',user:'',pass:''}` и впишите данные TURN-сервиса (например, бесплатный тариф metered.ca).
- Папки `functions` на GitHub Pages открываются публично, но секретов в них нет.
- Никому не присылайте пароли и коды из писем.
